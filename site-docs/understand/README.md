# Understand

Alder's types record facts that ordinary fitted pipelines often leave implicit:
why data exists, which target information a stage observed, whether prepared
rows may train another fitted stage, and which stage produced a failure.

Read these pages when you want to know why a composition is accepted or
rejected:

1. [Data roles and preparation scope](data-roles.md)
2. [Fitting and composition](fitting-and-composition.md)
3. [From convenience API to core algebra](convenience-and-core.md)
4. [Audit and reproducibility](audit-and-reproducibility.md)

You do not need these details before
[learning the first workflow](../learn/workflow.md). For a focused task, use
[How-to](../how-to/README.md).
